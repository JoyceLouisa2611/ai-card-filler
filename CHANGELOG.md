# Changelog

## 1.8.10
- Bigger, draggable image panel in the Review step (double-click the handle to reset).
- Remove several rows at once (Delete key, right-click, Ctrl/Shift select); edit a whole row; regenerate a single row with AI; suspicious rows are highlighted.
- Fill empty fields of existing notes from the Browser (right-click > "AI Card Filler: fill empty fields…").
- Long lists are split into chunks (default 20) with progress and resume.
- "Undo last add" button.
- Read a vocabulary list from a book-page photo (experimental).
- More AI providers: OpenAI-compatible (OpenAI, OpenRouter, Ollama, LM Studio) and Claude; automatic fallback when Gemini returns 429.
- Audio for Audio fields with Gemini TTS (experimental).
- Config presets (Chinese / Korean / English / Cloze), export and import.
